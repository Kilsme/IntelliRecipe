# Phase 0 - 5页行为基线清单

## login.html

- 支持登录/注册模式切换。
- 登录成功后跳转 `home.html`。
- 注册成功后切回登录模式并显示提示。

## profile.html

- 初始化读取用户信息并回填表单。
- 会话无效时提示并跳转 `login.html`。
- 保存时提交 JSON 化后的 `preferences/allergies`。

## recipe.html

- 支持按时段 + demand 生成菜谱。
- 展示标题、描述、风味标签、食材、步骤、替换说明、缺料说明。
- 收藏列表支持查看详情、去使用、单删、批量删除。
- “去使用”流程：`check -> (missing? modal) -> use`。
- 缺料弹窗支持：加购、去购物车、购买后重试、跳详情。

## recipe-detail.html

- 通过 `id` 加载菜谱详情。
- 支持评分与文字评价提交。
- 复用“去使用”流程并具备缺料弹窗。
- 返回行为：上一页 / 菜谱页 / 首页。

## home.html

- 显示用户名与会话状态。
- 冰箱：查看、添加、删除、按分类展示。
- 购物车：查看、添加、删除、单选完成采购入冰箱。
- 收藏快捷入口：查看详情、去使用、删除收藏。
- 支持 `returnRecipeId` 回跳到菜谱详情。
